# Projeto Salesforce — Estudos de Apex e Lightning Web Components

Projeto desenvolvido durante meus estudos práticos de desenvolvimento na plataforma Salesforce, reunindo exercícios de Apex, triggers, integrações e componentes Lightning Web Components (LWC).

O repositório também contém um **Carrinho de Compras**, desenvolvido com Apex e LWC, com funcionalidades voltadas à seleção de produtos e criação de oportunidades.

## 🛒 Carrinho de Compras

### Funcionalidades

- Listagem de produtos
- Pesquisa de produtos
- Paginação dos resultados
- Edição de preços e quantidades
- Cálculo do valor total do carrinho
- Seleção de conta
- Criação de oportunidade e inclusão de produtos
- Tela de confirmação

### Tecnologias

- Salesforce Platform
- Apex
- Lightning Web Components (LWC)
- JavaScript
- HTML
- Salesforce CLI
- Jest (configuração de testes de componentes LWC)

## 📚 Outros exercícios

O repositório reúne outros exercícios realizados durante meus estudos, incluindo:

- Classes Apex e wrappers
- Triggers
- Classes de teste Apex
- Componentes Lightning Web Components
- Integrações e chamadas de API
- Lógica de negócio e manipulação de dados

## 🗂️ Estrutura do projeto

- `force-app/main/default/classes/` — classes Apex e classes de teste
- `force-app/main/default/triggers/` — triggers
- `force-app/main/default/lwc/` — componentes Lightning Web Components
- `force-app/main/default/objects/` — metadados de objetos Salesforce
- `force-app/main/default/permissionsets/` — conjuntos de permissões
- `config/` — configurações do projeto
- `scripts/` — scripts auxiliares

## ⚙️ Ambiente de desenvolvimento

Projeto Salesforce DX configurado para utilizar a Salesforce CLI e uma organização Salesforce de desenvolvimento.

Versão da API Salesforce configurada: **67.0**.

## 🎓 Créditos

O Carrinho de Compras foi desenvolvido como parte dos meus estudos, com base no curso **Apex e LWC da Leverise**.

Este repositório reúne exercícios de aprendizagem e prática de desenvolvimento Salesforce.

## 👩‍💻 Objetivo

Consolidar conhecimentos em desenvolvimento Salesforce, Apex, Lightning Web Components e lógica de negócio, construindo um portfólio prático para oportunidades profissionais na área de tecnologia Salesforce.
